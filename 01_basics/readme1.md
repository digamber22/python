## 3. The Python Workflow

Python execution happens in **two main steps**:

### Step 1: Compilation to Byte Code

- Python first compiles source code (`.py`) into **Byte Code**.
- Byte Code is:
- Low-level
- Platform-independent
- Not machine code
- This Byte Code is stored in **`.pyc` files** inside the `__pycache__` folder.

**Important Note:**
- Python usually creates `.pyc` files only for **imported modules**, not for the main script you directly execute.
- This improves performance by reusing compiled Byte Code in future runs.

---

### Step 2: Python Virtual Machine (PVM)

- The generated Byte Code is executed by the **Python Virtual Machine (PVM)**.
- PVM is a runtime engine (a software loop) that:
- Reads Byte Code
- Executes it line by line
- Produces the final output
- Because Byte Code is interpreted by the PVM, Python is often called an **interpreted language**, even though it has a compilation step.

### Optimization
- Python uses diffing algorithms to detect changes in source code.
- If the code hasn’t changed, Python:
  - Skips recompilation
  - Reuses existing Byte Code
- This significantly improves execution speed.

---

## 5. Different Flavors of Python

Python has multiple implementations optimized for different platforms and use cases:

- **CPython** – Default and most widely used (written in C)
- **Jython (JPython)** – Runs on the Java platform
- **IronPython** – Integrated with the .NET framework
- **Stackless Python** – Optimized for concurrency and multitasking
- **PyPy** – Uses JIT compilation for better performance

---

## 6. Key Interview Takeaways

- **Byte Code ≠ Machine Code**
  - Byte Code cannot run directly on CPU hardware.
  - It requires the PVM.
- **Python is both compiled and interpreted**
  - Compiled to Byte Code
  - Interpreted by the Python Virtual Machine
